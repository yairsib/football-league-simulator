# Team Crest Sources

Real club crest images used in `frontend/public/crests/`. These are trademarked club
crests, used here strictly for team identification in a local, personal, non-commercial
project — the same purpose Wikipedia itself hosts them under (identification of the
subject of an article). No image is hotlinked at runtime; every file below was downloaded
once and is served locally by the frontend. If any rights holder objects to a specific
image being kept in this repository, delete the file — `TeamCrest` automatically falls
back to the existing gradient/initials badge for any team whose image is missing.

Sourced via the public MediaWiki API (`action=query&prop=images` / `imageinfo`) against
each club's own Wikipedia article, so every file below is the crest that Wikipedia's own
infobox displays for that club.
